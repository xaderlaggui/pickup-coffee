# Pickup Coffee app

Project: React + Vite app for the Pickup Coffee ordering experience.

## Working conventions
- Keep source work in src/.
- Prefer small, component-level updates.
- Do not treat generated build output, archives, or large installer binaries as source files.
- When editing UI, preserve the existing design system and keep behavior changes explicit.

## Current repo notes
- App entry: src/main.tsx
- Primary UI: src/App.tsx
- Styling: src/index.css
- Assets: src/assets/ and public/assets/

## Scope guardrails
- Ignore large binary or generated files unless the task specifically requires them.
- Keep prompts and code comments concise and project-specific.
